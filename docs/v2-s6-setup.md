Supabase → SQL Editor → New query → `supabase/migrations/0010_project_tasks.sql` の中身をすべて貼り付けて **Run**。

- 案件の工程（`project_tasks`）のテーブル
- 案件に出力先スプレッドシートの記録列

## S6-1 スプレッドシートから見積明細を取り込む（SQL 不要）

Web サイト制作・システム構築の見積（数十行）は、スプレッドシートで作った表をそのまま明細にできます。

```
見積書タブ → 明細追加バー「スプレッドシートから取込」
  ① Google スプレッドシート／Excel で、見出し行を含めて範囲をコピー → 貼り付け欄に貼る（自動で読み取り）
     または CSV ファイルを選ぶ
  ② 読み取り結果を確認（大カテゴリはプルダウンで変更可、不要な行はチェックを外す）
  ③ 「明細に追加」
```

- 列は見出し行から自動判定します: **項目／名称・数量・単位・単価・金額・原価・備考・大カテゴリ**（順不同）
- 「デザイン費関連」「企画・設計業務」のような**名称だけの行は見出し**として扱い、テキスト行になります。
  見出しに「デザイン」「構築」「印刷」を含むと、その下の行の大カテゴリを推定します
- 「▼以下、下層ページ」「小計」「合計」「消費税」の行は自動で除きます。名称の先頭の全角スペース・「・」は階層として残ります
- 「見出しごとに小計行を付ける」で、見出しの区切りごとに小計行が入ります
- 「テンプレートCSV」で、列の見本（大カテゴリ・名称・数量・単位・単価・原価・備考）をダウンロードできます
- 「コンセプト設計（全体予算の5%）」のような比率行は、シートの金額のまま取り込みます。必要なら削除して「自動計算行」に置き換えてください

いただいた3件の見積シート（HP制作・アクアマリン・スマート農業）で、合計金額まで一致して読み取れることを確認しています。

## S6-2 長い見積の体裁（SQL 不要）

- **小計行**: 明細追加バーの「小計行」で追加。直前の小計行（または先頭）からそこまでの合計を表示します。見積金額には含めません（内訳の表示用）
- **印刷**: 明細が多くても自動で改ページし、各ページに表の見出しを繰り返します。行の途中で改ページしません

## S6-3 工程管理表と Google スプレッドシート出力

案件詳細に **「工程」** の欄が増えます。

- 「標準の工程を入れる」で ヒアリング → 構成 → デザイン → 構築 → 公開 の8工程が入ります。工程名・担当（CV／クライアント／外注）・開始・終了・状態・備考をその場で編集できます
- **「スプレッドシートに出力」** で、操作した本人の Google ドライブに `工程管理表_P-xxxx_クライアント名` というスプレッドシートを作り、工程を書き出します。2回目以降は同じシートを書き換えます（アプリ側が正）
- 「クライアントに閲覧共有」をチェックすると、クライアント一覧のメールアドレスに閲覧権限を付けて共有します（通知メールが届きます）。画面から任意のアドレスは指定できません

### 必要な設定（Google 管理コンソール・1回だけ）

メール送信で使っているサービスアカウントに、スプレッドシートの権限を追加します。

[Google 管理コンソール](https://admin.google.com/) → セキュリティ → アクセスとデータ管理 → API の制御 → **ドメイン全体の委任を管理** → 既存の行（クライアント ID）を**編集** → OAuth スコープに次を追加して承認:

```
https://www.googleapis.com/auth/gmail.send
https://www.googleapis.com/auth/spreadsheets
https://www.googleapis.com/auth/drive.file
```

（既存の gmail.send はそのまま残し、2行を追加します。カンマ区切りで1つの欄に入れる画面の場合もあります）

Vercel の環境変数の追加は不要です（メール送信と同じ鍵を使います）。

| 症状 | 対処 |
|---|---|
| `unauthorized_client` | 上記スコープが委任に登録されていません |
| 共有できません（メールアドレス未登録） | クライアント一覧でメールを登録。シート自体は出力されています |
