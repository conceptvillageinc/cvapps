## S5-1 売上粗利管理表（サイドバー「売上粗利管理表」）

スプレッドシート「目標管理」と同じ4段構成（目標／着地見込／実績／計 × 12ヶ月＋年計）です。

| 段 | 元データ |
|---|---|
| 目標 | 「目標を設定」で入力（売上・仕入・目標粗利〔ジャンプ〕・必達粗利。年額→月割り、または月ごと）。目標粗利 = 売上 − 仕入 |
| 着地見込 | 進行中で受注確度 A / A（定期売上）の案件 → 売上（案件見込 A）・発注見込 A。要注意（A）は別行。完了予定日の月に計上。**請求済みの金額は差し引く**（二重計上しない） |
| 実績 | 売上（請求）= 請求書の税抜金額を請求日の月に。調達（仕入）= 入金確認で取り込んだ銀行明細の出金。その他原価（クレカ等）= 「目標を編集」で月ごとに手入力 |
| 計 | 実績＋見込。必要売上・必要粗利（ジャンプ／目標／必達）はマイナスが不足 |

- 粗利率は目標（システム設定「粗利率の目標」、初期値80%）以上を緑、未満を赤で表示します
- グラフは「売上」（実績＋見込の積み上げと目標線）と「粗利」（実績＋見込と目標・必達・ジャンプの線）を切り替えられます
- 「着地見込の内訳」で、月ごとにどの案件が見込に入っているかを確認できます
- 銀行明細に無い仕入（クレジットカード払いなど）は「目標を編集」の「実績 その他原価」に月ごとに入れてください。
  銀行の出金を使わず手入力にしたい月は「実績 仕入」に値を入れると、その値が優先されます

### スプレッドシートとの違い

- 見込は「案件の受注見込 − 請求済み」なので、請求が進むほど見込から実績へ自動で移ります（シートでは手で調整していた部分）
- 定期売上は案件の「A（定期売上）」として見込に含まれ、「うち定期売上」の行で内数が分かります

## S5-2 入出金予定表（サイドバー「入出金予定表」・SQL 不要）

今後3／6／12ヶ月の入金・出金を月別に見ます（税込）。

| 列 | 元データ |
|---|---|
| 入金予定（請求済） | 未入金の請求書を**入金期日**の月に（期日未設定なら請求日の翌月末） |
| 入金見込（未請求の案件） | 進行中で A／要注意（A）の案件の受注見込（税込換算）から請求済みを引いた額を、案件の**入金予定日**の月に |
| 支払予定（仕入見込） | 案件の発注見込＋その他費用（税込換算）を、案件の**仕入先 支払予定日**の月に（未設定なら完了予定日の翌月末） |
| 差引 | 入金予定＋入金見込 − 支払予定 |
| 入金実績 | 入金済の請求書を入金日の月に |

- 期日を過ぎた未入金は上部に「期日超過」としてまとめて出ます
- 各月の「内訳」で、どの請求書・案件が含まれているかを確認でき、クリックで開けます
- 案件の入金予定日・支払予定日は案件詳細の「編集」で変えられます（※11 の「まず」の段階。印刷所ごとの支払サイトは今後）

## S5-3 クライアントカルテ（クライアント一覧の「カルテ」アイコン、案件詳細のクライアント名・SQL 不要）

1社の情報を1画面に集めます。

- **要約**: 累計売上（税抜）・今期売上・未入金・進行中の案件数・最終請求日
- **基本情報**: 連絡先、請求書の送付方法、定期売上、入金確認で覚えた振込名義
- **メモ（カルテ）**: 担当者の好み、納品ルール、支払サイトなどを自由に記録（「保存」で確定）
- **案件・見積・請求書・納品書**の一覧（クリックで開く）
- **入稿先・仕入先（一次情報）**: 見積の明細に残っているネット印刷のURL・価格マスタ・仕入先見積を、見積番号・数量・原価・売価と一緒に表示。
  「あのラベルはどこで何円で刷ったか」を問い合わせ時にすぐ引けます
