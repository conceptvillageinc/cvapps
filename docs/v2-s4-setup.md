# v2 S4: 入金確認・会計データ出力の手順

## SQL（1回だけ）

Supabase → SQL Editor → New query → `supabase/migrations/0008_payments.sql` の中身をすべて貼り付けて **Run**。

- 銀行明細（`bank_transactions`）のテーブル
- クライアントに「覚えた振込名義」の列
- MF仕訳CSVの勘定科目の設定（初期値入り）

---

## S4-1 入金確認（サイドバー「入金確認」）

```
① 銀行のサイトで入出金明細をCSVでダウンロード（東邦銀行・琉球銀行の両方に対応。文字コードは自動判定）
② 「明細CSVを取り込む」 → 同じ明細は2回取り込まれません（新規◯件・取込済み◯件と表示）
③ 未照合の入金に、請求書の候補が表示されます
   ・緑の候補 = 金額が一致し、振込名義またはフリガナも合うもの
   ・「自動照合を適用」で、確度の高いものをまとめて入金済にできます
④ 候補が違う／出ないときは「請求書を選ぶ」で手動で選びます
⑤ 仕入先への支払い・手数料など請求書に関係ない明細は「対象外」にします
```

- 照合すると、請求書は**入金済**（入金日 = 着金日、入金額 = 着金額）になります
- 一度照合した振込名義はクライアントに記憶され、次回から自動候補になります
- 振込手数料が引かれた入金（差額 1,100円まで）も候補に出ます。差額は MF仕訳で「支払手数料」になります
- 間違えたときは「未照合に戻す」で請求書も送付済に戻ります

**照合の精度を上げるには**: クライアント一覧の**フリガナ**を入れておくと、初回から振込名義（カタカナ）と突き合わせられます。

### freee から取り込んだ過去の請求書について

【入金済】を付けていなかった423件は「送付済（未入金）」として入っています。過去の銀行明細CSVを取り込めば、
金額と名義でまとめて照合できます。古い分は「自動照合を適用」の後、残りを「請求書を選ぶ」か、
請求書の画面で「入金済にする」（入金日は請求日の翌月末など概算で可）で処理してください。

## S4-2 会計データ出力（サイドバー「会計データ出力」）

請求書の**売上計上**と**入金**を、MF会計の仕訳インポート形式（「マネーフォワード クラウド会計」形式・27列）の CSV にします。

| 仕訳 | 日付 | 借方 | 貸方 |
|---|---|---|---|
| 売上計上 | 請求日 | 売掛金（税区分 対象外） | 売上高（課税売上 10% / 軽減8%。税額を記載） |
| 入金 | 入金日 | 普通預金（補助科目 = 東邦銀行 / 琉球銀行） | 売掛金 |
| 振込手数料 | 入金日 | 支払手数料（差額） | 売掛金 |

- 対象月を選び、「売上計上」「入金」のどちらを含めるか選んで CSV をダウンロード（UTF-8・BOM付き）
- MF会計 → 会計帳簿 → 仕訳帳 → インポート → 「マネーフォワード クラウド会計」形式 で取り込みます
- **勘定科目・税区分・補助科目の表記**は会計事務所の MF の設定に合わせて画面下部で変更できます
  （初期値: 売上高／売掛金／普通預金／支払手数料／課税売上 10%／課税売上 8%（軽減）／対象外）
- 取込前に、会計事務所に「この形式で問題ないか」を1回だけ確認してください。列名や税区分の表記が
  違えば、設定の変更だけで合わせられます

軽減税率（8%）の明細がある請求書は、税率ごとに売上の仕訳が分かれます。
