# v2 S2: 見積フローの手順

S2 は「日常の見積作業」を新形式の見積書タブに集約するステップです。
段階ごとに追加される設定・SQL をここにまとめます。

---

## S2-1 値付けルール（SQL 不要）

システム設定 → **値付けルール** に、「デザイン制作原価売価計算表」の%と単価が入っています。
見積書タブでは次が使えます。

| 場所 | 機能 |
|---|---|
| 明細追加バー → **自動計算行** | コンセプト設計費（印刷費を除く合計の20%・5,000円単位切り上げ）／校正費（デザイン費の7%・1,000円単位切り上げ）／CV割引・Draw up 事業割引（デザイン費に対する値引き）。他の明細を変えると自動で計算し直されます |
| 自由入力・構築費 → **外注の仕入額から売価を出す** | 外注デザイン ÷0.6、構築 ÷0.75、外注撮影 ÷0.6 で売価を計算し 5,000円単位で切り上げ。仕入額は原価として粗利に反映 |
| 自由入力 → **時間単価チップ** | プロデュース 15,000円/時、社内デザイン 16,000円/時 などをクリックで単価に入れる |

%を変えると、**以降に追加する明細**から反映されます。すでに追加した自動計算行は追加時の%のままです（行を削除して追加し直すと新しい%になります）。

## S2-2 印刷仕様タブ

### SQL（1回だけ）

Supabase → SQL Editor → New query → `supabase/migrations/0006_print_specs.sql` の中身をすべて貼り付けて **Run**。

見積に「印刷仕様」の列、メール送信履歴に「どの仕様の依頼か」の列が追加されます。

### 使い方

新形式の見積詳細に **「印刷仕様」タブ** が増えます。流れは次のとおりです。

```
① 印刷仕様タブ   チラシ・ラベルなど、印刷物ごとに仕様を1件ずつ入力
                 （種別・サイズ・紙質・色数・枚数（複数可）・希望納期・加工・備考）
② メールタブ     依頼する仕様と送信先（印刷所情報のメール依頼先）を選び、AIでメール生成 → 送信
③ 見積書タブ     届いた見積書PDFを「仕入先見積から読込」で明細にする
```

- 印刷物種別を選ぶと、その種別の既定の依頼先（印刷所情報に登録があるもの）が送信先に自動でチェックされます
- 種別・枚数・希望納期が未入力の仕様には注意表示が出ます（未入力でも依頼はできます）
- 1つの見積で複数の印刷物を扱うときは「印刷仕様を追加」で増やします。似た仕様は複製できます
- 送信履歴には、どの仕様の依頼だったかが残ります

印刷仕様が1件も無い見積では、従来どおり見積書の明細から依頼メールを作ります。

## S2-3 ネット印刷の取込 → 価格マスタへ自動登録（SQL 不要）

見積書タブの明細追加バーに **「ネット印刷から取込」** が増えました。

```
① 価格ページのURLを貼る → 「URLから読込」（ページが読めないときは「スクショ/PDF」）
② 大カテゴリ・参照メーカー（URLから自動推定）・仕様を確認
③ 読み取った価格表（枚数×納期）から使うセルをクリック（複数可）
④ 「価格マスタに登録して明細に追加」
```

- 価格マスタには **URL・スクショ・読み取った価格表・選んだセル** がそのまま登録されます。後日「価格マスタ」画面の「URLから更新」で価格改定を追えます
- **同じURLがすでに価格マスタにある場合は新規作成せず更新**します（選択済みセルは残ります）
- 明細には原価（1枚あたり）と掛け率が入り、粗利に反映されます。掛け率はシステム設定「値付けルール」の値です
- 印刷仕様タブで種別を入れてあれば、大カテゴリの初期値になります

## S2-4 過去見積からの複製（SQL 不要）

見積書タブの明細追加バーに **「過去見積から複製」** が増えました。

- 既定は **同じクライアントの過去見積**だけを表示します。「他のクライアントの見積も含む」で全体に広げられます
- 見積番号・件名・明細名で絞り込めます
- 各明細に **前回の数量・原価・売価・入稿先**（印刷所名、ネット印刷ならURLへのリンク）が出ます
- 明細ごと、または見積ごとにチェックして「選択した明細を複製」。複製した明細には「前回: CV-2607-003 から複製」の印が付きます
- 複製後は数量・単価を必要に応じて直してください。コンセプト設計費などの自動計算行は複製されません（必要なら「自動計算行」から追加）
- 旧形式（仕様・印刷費タブ）の見積は、印刷費1行として複製できます

## S2-5 旧形式の見積を新形式に変換（SQL 不要）

旧形式（仕様・印刷費・デザイン費・プレビューのタブ）の見積を開くと、上部に
**「この見積は旧形式です」** の案内と **「新形式に変換」** ボタンが出ます。

変換すると次のようになります。

| 旧形式 | 新形式 |
|---|---|
| 印刷費タブで選んだ印刷所の出し値・原価 | 見積書タブの明細1行（印刷費）。原価・掛け率も引き継ぎ |
| デザイン費タブの各項目 | 明細（デザイン費）に1行ずつ |
| 校正費・その他費用 | 明細に1行ずつ |
| 仕様タブ（種別・サイズ・紙質・枚数・色数・希望納期） | 印刷仕様タブの1件 |

- 変換後の見積金額（税込）はボタンの横に事前表示されます
- 変換は1件ずつ、ボタンで行います（自動では変換しません）
- 旧形式の入力内容はデータとして残るため、元に戻すことも、過去見積の複製元として使うこともできます
- すべての旧形式の見積を変換し終えたら、旧形式のタブと関連コードを削除します（お知らせください）
