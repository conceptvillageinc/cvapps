# v2 S3: 納品書・請求書の手順

S3 は「見積 → 納品書 → 請求書 → 入金」の流れを作るステップです。

---

## S3-1 納品書・会社情報・電子印鑑

### SQL（1回だけ）

Supabase → SQL Editor → New query → `supabase/migrations/0007_documents.sql` の中身をすべて貼り付けて **Run**。

- 納品書（`delivery_notes`）・請求書（`invoices`）のテーブルと採番（`D-YYMM-連番` / `I-YYMM-連番`）
- 会社情報の初期値（登録番号 T7011001094049、福島・沖縄の所在地、東邦銀行・琉球銀行の振込先）
- メール送信履歴を請求書の送付にも使えるよう拡張

### システム設定 → 会社情報（帳票用）

初期値が入っているので、内容を確認して必要なら直してください。

| 項目 | 帳票での使われ方 |
|---|---|
| 会社名・代表者/担当者名 | 自社欄の1行目（例: 株式会社コンセプト・ヴィレッジ　馬場大治） |
| 登録番号 | 請求書の「登録番号」 |
| 所在地 | 納品書は1つ目だけ、請求書はすべて |
| 振込先 | 請求書の「振込先」欄 |
| **電子印鑑** | 「印影の画像を選ぶ」でPNGをアップロード。納品書・請求書の自社欄に重なります |
| 備考の既定文 | 新しく作る納品書・請求書の備考に最初から入ります |

印影は非公開の保存領域に置かれ、PDF生成時にサーバー側で読み込みます。URLが外部に出ることはありません。

### 納品書の使い方

```
見積詳細（新形式）→「納品書を作成」   見積の明細・件名・クライアントを引き継いで作成
案件詳細 →「納品書を作成」            明細は空。「見積から明細を取り込む」で案件の見積を選べる
サイドバー「納品書」                  一覧（未請求・下書きで絞り込み）
```

- 明細は摘要・数量・単位・単価・税率（10% / 8%）を直接編集できます。消費税は税率ごとに合計してから計算します（切り捨て）
- 番号は**納品日の年月**で採番されます。「作成」を押した時点で確定します
- **PDF** ボタンでA4のPDFを生成します（20行を超えると自動で複数ページ）
- 請求書にまとめた納品書は編集できなくなります（請求書側で外すと再び編集できます）

## S3-2 請求書（SQL 不要。0007 に含まれています）

```
納品書 →「請求書を作成」     その納品書の明細を引き継いで作成。同じクライアントの未請求の納品書もまとめられる（※8）
案件詳細 →「請求書を作成」   明細は空。納品書をチェックして取り込むか、直接入力
サイドバー「請求書」          期ごとの一覧。未入金／期日超過／入金済で絞り込み。未入金の合計を表示
```

- 請求日を入れると**入金期日は翌月末**が自動で入ります（変更可）
- 明細には**取引日**（納品日）が付き、PDFの「取引日」列に出ます
- 送付方法はクライアント一覧の設定（freee送付／郵送／個別メール／持参）を写します
- 状態: 下書き → **送付済**（「送付済にする」またはメール送付で自動）→ **入金済**（「入金済にする」で入金日・入金額を記録）
- 請求書にまとめた納品書は「請求済」になり、請求書を削除すると未請求に戻ります
- 入金済の請求書は編集できません（「入金を取り消す」で戻せます）

## S3-3 メール送付（PDF添付）

納品書・請求書の画面の **「メール送付」** で、PDFを添付してクライアントへ送ります。

- 宛先は**クライアント一覧のメールアドレス**です。未登録の場合は送れません（画面から任意のアドレスは指定できません）
- 差出人はログイン中のご自身のアドレス。`GMAIL_ALWAYS_CC` を設定していれば控えがCCされます
- 件名・本文はひな形が入ります（会社名・担当者名・振込先はシステム設定の会社情報から）
- 送ると請求書は「送付済」、納品書は「発行済」になり、送付履歴が画面に残ります
- 郵送・持参のクライアントには「PDF」ボタンで保存して印刷してください

## S3-4 freee の請求書（598件）の取込（任意）

freee の請求書一覧エクスポートを、請求書として取り込めます。取込SQLは生成済みでチャットでお渡ししています
（`seed_freee_invoices_1.sql` 〜 `_4.sql`。番号順に SQL Editor で Run）。

| freee | アプリ |
|---|---|
| 請求No.（INV-0000000655） | 請求書番号はそのまま。新規発行分は `I-YYMM-連番` なので混ざりません |
| 件名の先頭の【入金済】 | 状態 = 入金済（入金日は不明のため空） |
| 送付ステータス true | 状態 = 送付済 |
| 請求金額(税抜) | 小計。消費税10%で計算し、明細1行にまとめます |
| 請求先名称のタグ（【freee送付】など） | 剥がしてクライアント一覧と突合 |

取り込み後、**【入金済】を付けていなかった過去の請求書は「送付済」＝未入金として表示**されます。
実際には入金済みのものが多いはずなので、S4（銀行明細との照合）で一括で確認できるようにします。
それまでは請求書一覧の期を切り替えて確認するか、必要なものだけ「入金済にする」で記録してください。

自分で作り直す場合:

```bash
node scripts/import-freee-invoices.mjs <freeeの請求書CSV> supabase/seed_freee_invoices.sql --chunk 150
```
