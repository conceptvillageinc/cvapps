## 回答

**25 承認済みのあと**
承認済みになった見積は、そのまま「PDF」→ クライアントへ送付（メール or 印刷）→ 案件の受注確度・フェーズを更新（バージョン欄で変更可）→ 受注したら「納品書を作成」→ 納品書から「請求書を作成」の流れです。承認後に内容を直す場合は「複製」で改訂版を作る運用を想定しています（元の版は残ります）。承認済みの見積を直接編集できないようロックしたい場合はお知らせください。

**26 納品書作成で見積内容が自動入力される理由**
`納品書を作成` は「見積の明細から納品書の下書きを作る」ボタンなので、開いた瞬間に見積の明細が入ります（そのあとは自由に編集できます）。「更新（リロード）を押すと入り直す」のは、**まだ一度も保存していない**下書きを再読み込みしたためです。一度「保存」すると URL が `/delivery-notes/{ID}` に変わり、以後は保存した内容が出ます。保存前に離れると消える点は、他の帳票と同じです。

**30 実績粗利の計算式**
- 案件の「粗利（実績）」= 受注合計 − 発注合計（案件の編集で入力した数字。受注合計は請求書の税抜額、発注合計は仕入先への支払額）。
- 売上粗利管理表の「実績」= 売上（請求書の税抜合計）− 調達（入金確認で取り込んだ銀行明細の出金。手入力の「実績仕入」があればそちら）− その他原価（目標編集の手入力）。
- 表に反映されるのは、請求書を登録すること／銀行明細を取り込むこと（または「目標を編集」で実績仕入を入れること）です。

**31 入出金予定表の軸**
- 入金 = 請求書の **入金期日**（未入金のもの）＋ 案件の **入金予定日**（受注見込 A の案件で、まだ請求していない分）。
- 出金 = 案件の **支払予定日**（発注見込）。
月ごとに集計し、税抜で表示しています。

**32 定期売上**
クライアント一覧の「定期」チェックは印（一覧・カルテのラベル）で、案件を自動で作るのは **「定期売上のひな形」**（案件一覧 → 定期売上）に登録したものだけです。ひな形から毎月1日に案件が生成されます。クライアントの「定期」を入れただけでは案件は作られません。

## レイアウト（No.6・24・36・38）

参考 PDF（CV-2609-011）で気になった点をこう直しました。

- 冒頭の金額: 3マスの大きな帯 → **1行の帯**（見積金額（税込）を大きく、小計・消費税は右に小さく）。
- 宛名・自社情報の上下幅を詰め、印影は自社情報の右に重ねる（印影ありのときは自社情報を折り返して重ならないように）。
- 明細: 名称が長い行は折り返して行の高さを伸ばす。見出し行は薄い帯、小計行は右寄せ太字。
- ページをまたぐときは表の見出しを繰り返し、ページ番号を下に出す。
- 税率別内訳は右下に小さく。備考は文章量に合わせた高さ（無ければ出さない）。
- 納品書・請求書の印影も同じサイズ設定に従います。

見た目の微調整（フォントサイズ、余白、帯の色など）は PDF を見てからで構いません。ブラウザ印刷（「印刷用に新しいタブで開く」）はそのまま残しています。

**7 税率（税込見積・8%）** — 提案
- ① 税込見積: 見積ごとに「税込で作る」スイッチを付け、ON のときは単価・金額を税込で入力し、見積書には「税込」表記＋内訳（税抜・消費税）を出す。デフォルトは現状（税別）。
- ② 8%: 明細行に「税率」（10% / 8%）を持たせ、8% の行には「（軽減8%）」を付けて税率別に消費税を計算。納品書・請求書はすでに行ごとの税率に対応済みなので、見積も同じ形にします。見積書 PDF は行に tax_rate があれば税率別に集計するところまでは対応済みです（入力欄がまだありません）。
- この 2 つで進めてよいか、① の「税込のときの単価の丸め（税込単価から逆算するか）」だけ決めてください。

**9 発注書の雛形** — 提案
見積詳細に「発注書を作る」ボタンを付け、**宛先 = CV、発行元 = クライアント名（住所・担当者はクライアント台帳から）** の PDF を出す。内容は見積の明細（税別・税込）と「上記のとおり発注いたします。発注日／ご担当者／ご署名」の欄。番号は見積番号に `-PO` を付ける。クライアントに記入して返してもらう前提なので、印影なし・署名欄あり。これでよければ実装します。

**10 入稿URL・スクショ・備考 / カルテの見積一覧** — 提案
- ① 見積の明細に「入稿先 URL」と「スクショ」を持てるようにし（ネット印刷取込の URL は既に残っています）、見積書タブの社内確認表示で URL とサムネイルを表示、クリックで開く。備考は明細行の「メモ」欄（社内用・見積書には出ない）。
- ② クライアントカルテには既に見積一覧が出ています。「社内見積のシート」の代わりにカルテを使う形でよいか、カルテに足りない項目があれば教えてください。

**17 印刷費を商品カテゴリ順で選ぶ** — 提案
「印刷費（紙）」を押したときの一覧を、現在の「参照メーカー順」から **大カテゴリ（チラシ／パンフレット／名刺／パッケージ…）→ サイズ・仕様 → メーカー** の階層にする。価格マスタの「大カテゴリ」がそのまま使えるので、追加の入力はありません。同じ商品で複数メーカーがあるときは、メーカーごとの原価と出し値を横並びで比較して選べる形にします。

**35 CSV テンプレートに仕入金額** — 案
テンプレートの列を次の形にします（既存の CSV も読めます。「原価」列は今も読み取り対応済み）。

```
大カテゴリ, 名称, 数量, 単位, 単価（税別）, 仕入単価（税別）, 備考
デザイン費, トップページデザイン, 1, ページ, 150000, 60000,
構築費, 下層ページ構築, 20, ページ, 5000, 3000, 外注A社
```

仕入単価が入った行は原価として持ち、見積の社内確認表示と見積一覧・案件に粗利・粗利率が出ます。仕入は「単価」か「合計」か、どちらで書きたいかだけ決めてください（案は単価）。
