# CV AX KIT アシスタント（Chrome 拡張機能）

CV アプリ（https://cv-ax.jp）の「印刷仕様の一覧」で「グラフィックで調べる」を押したときに、
お使いの Chrome でグラフィック（https://www.graphic.jp/）のページを別ウィンドウで開き、
AI の指示どおりに仕様を選んで、価格・URL・スクリーンショットを CV アプリに返します。

- 何を押すかは CV アプリのサーバー（AI）が決めます。拡張機能は「開く・読む・押す・撮る・閉じる」だけをします。
- ログイン情報・パスワード・API キーは持ちません。グラフィックにはログインせずに価格を見ます。
- 頼みを受けるのは cv-ax.jp のページからだけです。操作するのは、この拡張機能が開いたグラフィックのタブだけです。
- ログイン・会員登録・カート・注文・入稿・お問い合わせなどのボタンは押しません（CV アプリ側で止めます）。
- 操作の間は 2 秒以上あけ、1 回に調べるのは 10 品目までです（先方のサーバーに負担をかけないため）。

権限について: スクリーンショットを撮る機能（chrome.tabs.captureVisibleTab）が「すべてのサイト」の権限を必要とするため、
`<all_urls>` を入れています。実際に開いて操作するのはグラフィックのタブだけです（background.js の isGraphicUrl で確かめています）。

## 試しに入れる（1 台だけ）

1. このフォルダ（`extension/`）を PC に置く（GitHub からダウンロード、または配布された zip を展開）
2. Chrome で `chrome://extensions` を開き、右上の「デベロッパー モード」をオンにする
3. 「パッケージ化されていない拡張機能を読み込む」でこのフォルダを選ぶ
4. CV アプリのページを読み込み直す（印刷仕様の一覧の画面に「拡張機能 v1.0.0」と出れば OK）

## 社内の PC に配る（Google Workspace）

1. このフォルダを zip にする（`manifest.json` が zip の一番上に来るように）
2. Chrome ウェブストアのデベロッパー ダッシュボード（https://chrome.google.com/webstore/devconsole）に、
   会社の Google アカウントで登録する（初回のみ登録料 5 ドル）
3. 「新しいアイテム」で zip を上げ、公開範囲を「非公開」→「concept-village.co.jp のユーザーだけ」にして公開する
4. Google 管理コンソール →「デバイス」→「Chrome」→「アプリと拡張機能」→「ユーザーとブラウザ」で、
   公開した拡張機能を追加し、「強制インストール」にする
5. 社員の Chrome に自動で入る（反映まで数時間かかることがあります）

更新するときは `manifest.json` の `version` を上げて、ダッシュボードで新しい zip を上げます。
